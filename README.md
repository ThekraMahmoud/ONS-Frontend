# أُنس | واجهات خدمة ضيوف الرحمن

تطبيق React مبني باستخدام Vite. الواجهات باللغة العربية وتدعم اتجاه RTL.

## هيكل المشروع

```text
src/
├── assets/       الصور والشعارات
├── auth/         تسجيل الدخول والحسابات التجريبية
├── components/   المكونات المشتركة
├── pages/        صفحات التطبيق المرتبطة بالمسارات
├── services/     الاتصال بالـ API وتخزين بيانات الحملة
├── styles/       تنسيقات الصفحات
├── App.jsx       تعريف المسارات
└── main.jsx      نقطة تشغيل React
```

## المسارات

- `/` الموقع العام والتعريف بالخدمة وتدفق الأدوار.
- `/login` تسجيل الدخول بالبريد الإلكتروني.
- `/register` تسجيل حملة جديد.
- `/payment` ملخص الطلب وخطوة تفعيل الحملة.
- `/dashboard` مساحة داخلية منفصلة تتغير حسب دور المستخدم:
  - مدير الحملة: نظرة عامة، إدارة الفريق، إدارة الحجاج، والبلاغات.
  - المشرف: نظرة عامة، إدارة المندوبين المسندين إليه، والبلاغات.
  - المندوب: المهام وبلاغات المساعدة فقط.

## حسابات العرض التجريبية

- مدير الحملة: `campaign@test.com` / `Campaign123!`
- المشرف: `supervisor@test.com` / `Supervisor123!`
- المندوب: `representative@test.com` / `Representative123!`

## التشغيل

```sh
npm install
npm run dev
```

إضافة الحملة تستخدم `POST /api/v1/campaigns/add`. الدفع وإدارة أعضاء الحملة في الواجهة الحالية تجريبية، وتُحفظ بياناتهما محليًا في المتصفح إلى حين ربط الخدمات الفعلية.

التحكم بالصفحات في الواجهة يوضح صلاحيات الأدوار لتجربة التدفق. يجب تطبيق والتحقق من الصلاحيات نفسها في الخادم قبل الاستخدام الفعلي.
